✨ What's new

This build implements the Reels-user roadmap through v2.4, plus several of the "additional ideas" from the roadmap's bonus list (monetization and true live speech-to-text excluded).

  • v2.0 — swipe/long-press gestures, playback-speed pill, always-on progress bars, 5 transition styles, thumbnail history.
  • v2.1 — CSS filter carousel with intensity, overlay FX (grain/vignette/scanlines/letterbox/leaks), loop/replay/save clips, drag & drop, demo clips, installable PWA.
  • v2.2 — dual-track background audio mixer with crossfader & auto-duck, audio file scanning.
  • v2.3 — M3U/PLS/JSON/XSPF playlist import, shuffle vs. playlist mode, drag-to-reorder queue.
  • v2.4 — Mix Jams audio-only DJ mode with visualizer, sidecar .srt/.vtt caption support.
  • Latest — Auto/Light/Dark/AMOLED themes with 5 accent colors; a fully responsive layout tuned for laptops, tablets, and modern phones; text overlays; "remix" a saved clip; sound discovery (extract a snippet's audio into the mixer); session recap; Focus/Study mode; an "up next" preview; exporting a snippet as a downloadable video file; audio files now play in the main shuffle with real extracted album art; and a standalone 🖼 Photo Slideshow mode — pick a photo album and a songs folder and it flips photos on a timer while music plays.
